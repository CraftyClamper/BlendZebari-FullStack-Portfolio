# 🏢 Microsoft Enterprise Ecosystem & Audit Simulator

An isolated, zero-dependency C# .NET execution sandbox and real-time Blazor dashboard designed to simulate the pro-development execution lifecycle of the **Microsoft Power Platform, Dynamics 365 CE, Dataverse, SharePoint, and Azure Compliance architectures** entirely in-memory.

---

## 🚀 System Architecture & Capabilities

This simulator mimics complex enterprise cloud topologies within a thread-safe, high-performance C# .NET host environment. It intercepts data inputs via an interactive Blazor interface and passes them down an simulated execution pipeline:

## 🛠️ Component Technical Breakdowns

### 1. Dynamics 365 CE & Dataverse Pipeline (`DataversePipeline.cs`)
Simulates execution pipelines with native enterprise plug-in rules:
* **Stage 10 (Pre-Validation):** Evaluates incoming transaction packages against corporate guidelines. For example, if a `creditlimit` is assigned a negative integer, the pipeline throws an intentional `InvalidOperationException` and aborts the state machine.
* **Core Relational Database Commit:** Manages logical representation entities (`CrmEntity`) utilizing string-keyed attribute dictionaries.
* **Stage 40 (Post-Operation):** Intercepts successful core commits to trigger asynchronous hooks and configure downstream workspace mock file shares.

### 2. Power Automate Orchestration (`PowerAutomateEngine.cs`)
Implements an asynchronous multi-threaded cloud flow runner using a thread-safe `ConcurrentQueue<AutomationJob>` background worker loop:
* **Webhook Hooks:** Intercepts automation triggers generated by successful core Dataverse events.
* **Asynchronous Processing:** Processes queued jobs sequentially off the thread heap using `Task.Run` background worker loops to prevent interface locking.

### 3. SharePoint Document Management Layer
When a `Create` event succeeds inside the database layer, the simulator spins up automated repository generation mechanisms:
* Programmatically constructs physical file structures under regional directories matching enterprise hierarchies (`/sites/Finance/Documents/...`).
* Generates system metadata manifest files (`sharepoint_metadata.txt`) documenting target records' immutable structural unique GUID origins.

### 4. Compliance Audit Ledger (`AuditHistoryRecord.cs`)
An append-only historical tracking database capturing state changes:
* **Delta Comparison Engine:** On `Update` execution messages, the engine checks tracking pre-images against current entity attributes to calculate specific differential shifts.
* **Telemetry Reporting:** Converts modified parameters into clear text streams documenting exactly what fields transformed from past inputs to new variables.

## 📡 Control Portal UI (`EcosystemSimulator.razor`)

The interactive Blazor dashboard features:
* **Power Apps Data Entry Form:** Dynamically shifts context configurations depending on active state parameters (automatically changing options between default `Create` pipelines and differential data updates).
* **System Telemetry Output Monitor:** A real-time system terminal catching logged telemetry across all active frontend and backend sandbox operations.
* **Dynamics 365 Style Audit History Grid:** Renders chronological database logs detailing modified parameters, operations, timestamps, and audit identities.

### 🖥️ Option 1: Running via Visual Studio 2026 (Recommended)

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/CraftyClamper/BlendZebari-FullStack-Portfolio.git
   cd BlendZebari-FullStack-Portfolio
   ```

2. **Open the Solution:**
   * Double-click the **`Portfolio.slnx`** file at the root of the repository to launch it directly in Visual Studio 2026.

3. **Configure Startup Projects:**
   * Right-click the Portfolio.Server in the *Solution Explorer* and choose **Set as Startup Project**
   
4. **Launch the Application:**
   * Press **`F5`** (Debug mode) or **`Ctrl + F5`** (Without debugging) to build and launch the application.
   * Your default web browser will automatically open to the local server hosting the Blazor control panel.
